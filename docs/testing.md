# E2E Testing

This project uses Playwright.

## Install

```bash
pnpm playwright install
```

## Run Tests

```bash
pnpm test:e2e
```

## Run UI Mode

```bash
pnpm test:e2e:ui
```

## Run Headed Mode

```bash
pnpm test:e2e:headed
```

## Covered Scenarios

- Business page rendering
- Search business
- Category filtering
- Pagination
- Responsive behaviour
