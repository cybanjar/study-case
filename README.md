---

# Why This Tech Stack

## Nuxt 4

Chosen because:

- SSR support
- SEO friendly
- File-based routing
- Excellent TypeScript support
- Production-ready architecture

## TypeScript

Chosen because:

- Strong type safety
- Better maintainability
- Easier refactoring
- Improved developer experience

## Nuxt UI

Chosen because:

- Official Nuxt ecosystem
- Accessible components
- Modern design system
- Faster development

## Pinia Colada

Chosen because:

- Server state management
- Query caching
- Request deduplication
- Better developer experience

# Pre-Installation
- Node.js >= 22
- pnpm

## Mac or Linux

```bash
git clone https://github.com/cybanjar/study-case.git

cd study-case

pnpm install
```

Run Development:

```bash
pnpm dev
```

Build:

```bash
pnpm build
```

Preview:

```bash
pnpm preview
```
